# UtilityFree

**UtilityFree** — это бесплатная и быстрая системная утилита для Windows, созданная для упрощения работы с операционной системой. Она объединяет важные системные инструменты в одном удобном графическом интерфейсе, избавляя от необходимости искать их в дебрях настроек Windows.

> Важно: Проект находится на стадии альфа-тестирования. Функционал активно дорабатывается, поэтому возможны баги и сырые механики. Если вы нашли ошибку или хотите предложить идею, пожалуйста, напишите об этом в раздел [Issues](https://github.com/MaximErevanV3/UtilityFree/issues).

---

## Основной функционал

Программа позволяет в один клик запускать ключевые компоненты Windows:
* Командная строка — быстрый доступ к CMD.
* Microsoft Defender — проверка безопасности системы.
* Диспетчер задач — мониторинг процессов и нагрузки.
* Редактор реестра — быстрое открытие Regedit.
* PowerShell — запуск продвинутой консоли автоматизации.
* Проводник и Браузер — мгновенный переход к файлам и веб-серфингу.

Со временем полезных инструментов и функций станет гораздо больше!

## Инструкция по установке и запуску

1. Скачайте актуальную версию по прямой ссылке: [Релиз 1.3.5 (Март 2025)](https://github.com/MaximErevanV3/UtilityFree/releases/tag/UtilityFree1.3.5).
2. Распакуйте содержимое скачанного ZIP-архива в любую удобную папку на вашем компьютере.
3. Запустите исполняемый файл Utility Free.exe (внимание: запускайте обычную версию, а не файл с припиской console).

## План развития (Roadmap)

Что планируется добавить в ближайших обновлениях:
- Отображение характеристик ПК (вывод информации о модели CPU и GPU).
- Инструменты очистки (удаление временных файлов и кэша системы).
- Кастомизация интерфейса (выбор тем оформления и прозрачность окон).
