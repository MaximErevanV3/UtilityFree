# UtilityFree v1.5

**UtilityFree** — это бесплатная, легковесная и быстрая системная утилита для Windows, созданная на движке Godot Engine 4. Она объединяет ключевые инструменты администрирования ОС в одном отзывчивом графическом интерфейсе, избавляя от необходимости искать их в дебрях настроек Windows.

> ⚠️ **Важно:** Проект находится в раннем доступе. Функционал активно дорабатывается, поэтому возможны баги. Если вы нашли ошибку или хотите предложить идею, пожалуйста, напишите об этом в раздел [Issues](https://github.com/MaximErevanV3/UtilityFree/issues). Ваша обратная связь очень важна для развития проекта!

---

## 🔥 Что нового в версии 1.5?

* **Интеграция экосистемы «NeBlock»:** Прямой доступ к авторской социальной сети прямо из интерфейса утилиты. Общайтесь и делитесь опытом, не открывая браузер!
* **Криптографический генератор паролей:** Полностью переработанный алгоритм на базе класса `Crypto`. Гарантирует создание криптостойких 16-значных паролей и автоматически копирует их в буфер обмена Windows.
* **Улучшенная стабильность:** Автоматическое сканирование дерева сцен предотвращает вылеты интерфейса, а корректное уничтожение процессов WebView освобождает ОЗУ при закрытии вкладок.

## 🛠 Основной функционал

Программа позволяет в один клик взаимодействовать с ключевыми компонентами Windows:
* **Командная строка** — мгновенный запуск классической CMD.
* **PowerShell** — быстрый доступ к продвинутой консоли автоматизации.
* **Microsoft Defender** — оперативная проверка безопасности системы.
* **Диспетчер задач** — мониторинг процессов и текущей нагрузки на ПК.
* **Редактор реестра** — открытие Regedit с автоматической фокусировкой на ветке автозагрузки (Run).
* **Проводник и Браузер** — удобный переход к файловой системе и веб-серфингу.

## 🖥️ Системные требования

Программа оптимизирована для работы на широком спектре устройств и практически не нагружает компоненты ПК во время фоновой работы.

| Компонент | Минимальные требования | Рекомендуемые |
| :--- | :--- | :--- |
| **Операционная система** | Windows 7 / 8 / 10 (32/64-bit) | Windows 10 / 11 (64-bit) |
| **Процессор (CPU)** | 2-ядерный с частотой от 1.5 ГГц | 4-ядерный с частотой от 2.4 ГГц |
| **Оперативная память** | 512 МБ RAM | 1 ГБ RAM (для плавной работы WebView) |
| **Видеокарта (GPU)** | Любая с поддержкой DirectX 11 / OpenGL 3.3 | Дискретная или встроенная с поддержкой DirectX 12 |
| **Место на диске** | ~120 МБ свободного пространства | ~150 МБ (с учетом кэша браузера NeBlock) |
| **Дополнительно** | Интернет-соединение для работы соцсети | Интернет-соединение + установленный VPN (при проблемах с сетью) |

## 📦 Инструкция по установке и запуску

1. Скачайте актуальную версию со страницы [Релизов](https://github.com/MaximErevanV3/UtilityFree/releases).
2. Полностью распакуйте содержимое скачанного ZIP-архива в любую удобную папку на вашем компьютере. *Не запускайте программу прямо из архива, иначе модуль соцсети выдаст ошибку!*
3. Запустите исполняемый файл `UtilityFree.exe`. 
   * *Примечание: Файл `UtilityFree.console.exe` предназначен только для разработчиков и тестов (он запускает программу вместе с логом ошибок в окне CMD).*
4. Если социальная сеть «NeBlock» выдает белый экран, проверьте ваше интернет-соединение или попробуйте использовать VPN.

## 🗺 План развития (Roadmap)

Проект развивается по системе ежемесячных стабильных мини-патчей. В ближайших обновлениях планируется:
- **Диагностика сети (Модуль «Пинг-мастер»):** Асинхронная проверка стабильности подключения без зависаний основного потока утилиты.
- **Отображение характеристик ПК:** Вывод подробной информации о моделях процессора (CPU) и видеокарты (GPU).
- **Инструменты очистки:** Быстрое удаление временных файлов системы и кэша.
- **Кастомизация:** Выбор тем оформления интерфейса и настройка прозрачности окон.
