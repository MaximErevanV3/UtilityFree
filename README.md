**UtilityFree** — это бесплатная легковесная системная утилита для Windows, созданная для упрощения работы с операционной системой. Она объединяет важные системные инструменты в одном удобном графическом интерфейсе, повышая вашу продуктивность и оптимизируя рабочий процесс.

> ⚠️ **Важно:** Проект находится на стадии **альфа-тестирования**. Функционал активно дорабатывается, поэтому возможны баги и сырые механики. Если вы нашли ошибку, пожалуйста, создайте [Issue](https://github.com).

---

## ✨ Основной функционал

Программа позволяет в один клик запускать ключевые компоненты Windows:
* 💻 **Командная строка** — быстрый доступ к CMD.
* 🛡️ **Microsoft Defender** — проверка безопасности системы.
* ⚙️ **Диспетчер задач** — мониторинг процессов и нагрузки.
* 📝 **Редактор реестра** — быстрое открытие Regedit.
* 🚀 **PowerShell** — запуск продвинутой консоли автоматизации.
* 📂 **Проводник и Браузер** — мгновенный переход к файлам и веб-серфингу.

*Со временем полезных инструментов и функций станет гораздо больше!*

## ⚙️ Спецификации и Системные требования

### Поддерживаемые ОС
* ✅ Windows 11
* ✅ Windows 10
* ✅ Windows 8 / 8.1
* ✅ Windows 7

### Технические детали
* **Движок:** Godot Engine 4
* **Язык разработки:** GDScript
* **Размер программы:** ~80 МБ

---

## 🚀 Инструкция по установке и запуску

1. Перейдите в раздел **[Releases](https://github.com)** и скачайте актуальный `ZIP-архив`.
2. Распакуйте содержимое архива в любую удобную папку на вашем компьютере.
3. Запустите исполняемый файл `Utility Free.exe` *(внимание: запускайте обычную версию, а не файл с припиской `console`)*.
