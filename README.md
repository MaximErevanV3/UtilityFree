# ⚡ UtilityFree

**Бесплатная, сверхлёгкая и быстрая системная утилита для Windows на движке Godot Engine 4**

🏷️ **Актуальная версия:** v1.5.2 • 🧪 **В разработке:** v1.5.3 (Декабрь 2026) • 📜 **Лицензия:** GPLv3 • 🪟 **ОС:** Windows 7–11

**UtilityFree** объединяет инструменты администрирования Windows, диагностики сети и безопасности в едином интерфейсе. 

---

## 🛡️ Философия проекта: никакого мусора

* 🆓 **100% бесплатно навсегда** без подписок, платных функций и скрытых платежей.
* 🔒 **Ноль телеметрии и слежки** — программа не собирает личные данные и не грузит фоновые службы.
* 🚫 **Без рекламы и баннеров** в единой тёмной палитре с фиолетовым акцентом.
* 📖 **Открытый исходный код** под свободной лицензией GNU GPLv3.

### 🧪 Обновление UtilityFree 1.5.3 — на этапе тестирования и полировки (Релиз: 1–5 декабря 2026)

## 🛠 Основной функционал

* 💻 **Системные консоли:** Быстрый запуск CMD и PowerShell.
* ⚙️ **Реестр и автозагрузка:** Прямой доступ к Regedit (ветка `Run`).
* 🛡️ **Безопасность и контроль:** Интеграция с Microsoft Defender, Проводником и Диспетчером задач.
* 🔐 **Крипто-генератор паролей** с аппаратной генерацией и расчётом энтропии.
* 🌐 **Браузер и NeBlock** на базе WebView2.
* 🐍 **Мини-игра «Змейка»** с таблицей рекордов.

---

## 💻 Спецификации и системные требования

* 🪟 **ОС:** Windows 7 / 8 / 10 / 11 (32/64-bit)
* 🧠 **RAM:** от 512 МБ (в грядущей v1.5.3 снижено до ~104 МБ в покое)
* 🎮 **Графика:** OpenGL 3.3 / DirectX 11

---

## 📦 Установка и запуск

1. 📥 Скачайте архив из раздела [Релизов](https://github.com/MaximErevanV3/UtilityFree/releases/).
2. 📂 Полностью распакуйте файлы в отдельную папку на диске.
3. 🚀 Запустите `UtilityFree.exe`.
